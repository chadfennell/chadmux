# Chadmux

An opinionated `tmux` configuration.

Use this in conjunction with [AgentIncus](https://github.com/MixTapeSoftware/agent_incus) as an 
ergonomic wrapper around incus containers for local development.

## Cheat sheet

Press `C-s H` for a popup of the common keys (see [help.txt](help.txt)), or
`C-s K` for a longer, scrollable list of movement keys ([help-more.txt](help-more.txt)).
